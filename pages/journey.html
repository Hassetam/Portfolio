MY STORY

The Journey

Every step has taught me something new. This timeline reflects how curiosity slowly turned into confidence and a passion for building software.

Sep 2024 Beginning

Started My Software Engineering Journey

Began learning the foundations of software engineering through common first-year courses. Although programming had not started yet, this period helped me build the problem-solving mindset that would prepare me for the semesters ahead.

Feb 2025 Python

My First Programming Language

Started learning Python. At first, programming felt confusing and intimidating, and I struggled to understand many concepts. Instead of giving up, I kept practicing until coding slowly began to make sense.

Jul 2025 Bootcamp

Fell in Love with Web Development

After the semester ended, I joined a web development bootcamp where I learned HTML, CSS, and JavaScript. Building websites for the first time completely changed how I viewed programming and made me excited to keep learning.

Oct 2025 C++ & Database

Building Strong Programming Foundations

Returned for a new semester and started learning C++ alongside Database Systems. Programming concepts became much clearer, and I gained confidence in writing code, solving problems, and designing databases.

Feb 2026 Java & Web

Turning Knowledge into Real Projects

My second semester became a major turning point. I developed a strong understanding of Java, Object-Oriented Programming, and modern web development while creating projects such as the Things I Love website, Puppy Lovers Page, Apple First Page Cloning, and a complete Gym Website.

Jul 2026 Current

Building Bigger Ideas

I'm currently developing two projects that represent my growth as a developer: this personal portfolio, designed to showcase my journey and skills, and the SMART Budget Planning System, a Java desktop application built with Swing, SQL Server, GitHub collaboration, and Object-Oriented Programming. Along the way, I've also learned Git, GitHub, SQL Server, responsive web design, and deployed projects using Vercel.
